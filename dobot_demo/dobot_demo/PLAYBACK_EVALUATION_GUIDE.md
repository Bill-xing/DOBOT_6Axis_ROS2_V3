# 播放评估系统使用指南

## 概述

播放评估系统用于评估数据集播放时机械臂的跟踪性能。系统包含两个核心工具：

1. **playback_evaluator.py** - 播放评估录制器
   - 在播放数据集时同步录制目标状态和实际状态
   - 保存为HDF5格式的评估数据

2. **analyze_playback.py** - 播放质量分析工具
   - 加载评估数据并计算跟踪误差
   - 生成统计报告和可视化图表

---

## 系统架构

```
数据流程：

dataset_player.py                    playback_evaluator.py
    |                                        |
    |-- 发布 /robot/target_pose ----------->|-- 订阅并录制
    |-- 发布 /gripper/command_update ------>|-- 订阅并录制
    |                                        |
    |                                        |-- 订阅 /dobot_msgs_v3/msg/ToolVectorActual (实际状态)
    |                                        |-- 订阅 /gripper/state_feedback (夹爪实际状态)
    |                                        |
    |                                        V
    |                               保存评估数据
    |                               playback_eval/evaluation_X.hdf5
    |                                        |
    |                                        V
    |                               analyze_playback.py
    |                                        |
    |                                        V
    |                               生成分析报告和图表
```

## 完整使用流程

### 步骤 1: 启动机械臂和相机系统

```bash
# 启动机械臂驱动
ros2 launch dobot_bringup_v3 ...

# 启动相机（如果需要）
ros2 launch realsense2_camera ...
```

### 步骤 2: 启动评估录制器

在**第一个终端**中启动评估录制器：

```bash
cd /home/hit/dobot_ws_xing/src/DOBOT_6Axis_ROS2_V3
python3 dobot_demo/dobot_demo/playback_evaluator.py
```

输出示例：
```

等待播放器发布话题...
```

### 步骤 3: 播放数据集

在**第二个终端**中播放数据集：

```bash

python3 dobot_demo/dobot_demo/dataset_player.py data/episode_1.hdf5
```

## 评估数据格式

### 文件结构

```
playback_eval/evaluation_0.hdf5
├── timestamp               (N,)      时间戳序列
├── robot/
│   ├── target             (N, 6)    机械臂目标状态 [x,y,z,rx,ry,rz]
│   └── actual             (N, 6)    机械臂实际状态 [x,y,z,rx,ry,rz]
└── gripper/
    ├── target             (N, 1)    夹爪目标位置 [0-1000]
    └── actual             (N, 1)    夹爪实际位置 [0-1000]
```

### 元数据 (Attributes)

- `total_frames`: 总帧数
- `evaluation_type`: 评估类型 ("playback")
- `recording_frequency_hz`: 录制频率（100Hz）
- `time_tolerance_ms`: 时间对齐容差（50ms）

## 分析报告说明

### 1. 跟踪误差统计

```
======================================================================
跟踪误差统计
======================================================================

[机械臂位置误差] (mm)
  平均值: 2.456 mm      ← 平均位置跟踪误差
  中位数: 2.123 mm      ← 中位数（更稳健的统计量）
  标准差: 1.234 mm      ← 误差波动程度
  最小值: 0.123 mm      ← 最好情况
  最大值: 8.567 mm      ← 最差情况
  95%分位: 5.234 mm     ← 95%的帧误差小于此值
  99%分位: 7.123 mm     ← 99%的帧误差小于此值

[位置分量误差] (mm)
  X轴: 平均=1.234, 最大=5.678   ← 各轴分量误差
  Y轴: 平均=1.456, 最大=6.789
  Z轴: 平均=0.987, 最大=4.321

[机械臂旋转误差] (deg)
  平均值: 0.456 deg
  ...

[夹爪位置误差] (0-1000)
  平均值: 12.345
  ...
```

**指标解读：**
- **平均值**：总体跟踪精度，越小越好
  - <1mm: 优秀
  - 1-3mm: 良好
  - 3-5mm: 中等
  - >5mm: 较差

- **标准差**：稳定性，越小越稳定
  - <1mm: 非常稳定
  - 1-2mm: 稳定
  - >2mm: 不稳定

- **最大值**：极端情况
  - <5mm: 可接受
  - 5-10mm: 需注意
  - >10mm: 存在问题

### 2. 跟踪质量评估

```
======================================================================
跟踪质量评估
======================================================================

[位置跟踪质量]
  优秀 (<1mm):   45.2% (508 帧)    ← 高精度帧比例
  良好 (<5mm):   89.3% (1004 帧)   ← 可接受精度帧比例
  较差 (>=5mm):  10.7% (121 帧)    ← 需改进的帧比例

[旋转跟踪质量]
  优秀 (<0.5°):  78.5% (883 帧)
  良好 (<2°):    95.2% (1071 帧)
  较差 (>=2°):   4.8% (54 帧)

[总体评级]
  评级: 良好
  建议: 跟踪精度良好，适合大部分任务
```

**评级标准：**
- **优秀**：平均位置误差<1mm，旋转误差<0.5°
  - 适合高精度任务（如精密装配）

- **良好**：平均位置误差<3mm，旋转误差<1.5°
  - 适合大部分任务（如抓取、搬运）

- **中等**：平均位置误差<5mm，旋转误差<2.0°
  - 需要优化控制参数

- **较差**：平均位置误差>=5mm，旋转误差>=2.0°
  - 需要检查系统配置

**用途：**

## 可视化图表说明

使用 `--plot` 参数生成6个图表：

### 1. Position Tracking Error (位置误差时序图)
- **横轴**: 时间 (s)
- **纵轴**: 位置误差 (mm)
- **红色虚线**: 平均值
- **橙色虚线**: 95%分位数
- **用途**: 观察误差随时间的变化趋势

### 2. Position Error Distribution (位置误差分布直方图)
- **横轴**: 位置误差 (mm)
- **纵轴**: 频率
- **用途**: 查看误差分布形状（是否正态分布）

### 3. Rotation Tracking Error (旋转误差时序图)
- 类似位置误差时序图

### 4. Gripper Tracking Error (夹爪误差时序图)
- 显示夹爪跟踪性能

### 5. Position Error Components (XYZ分量误差对比)
- **三条曲线**: X、Y、Z轴分量误差
- **用途**: 识别哪个轴的跟踪精度较差

### 6. Position Error CDF (误差累积分布函数)
- **横轴**: 位置误差 (mm)
- **纵轴**: 累积百分比 (%)
- **用途**: 快速查看"X%的帧误差小于Ymm"

## 常见问题排查

### Q1: 评估录制器没有接收到消息

**症状：**
```
[状态] 消息计数(过去2s): robot_target=0, robot_actual=0, ...
```

**可能原因：**
1. 播放器未启动
2. 话题名称不匹配
3. ROS2环境未正确配置

**解决方法：**
```bash
# 检查话题是否存在
ros2 topic list

# 应该看到以下话题：
# /robot/target_pose
# /dobot_msgs_v3/msg/ToolVectorActual
# /gripper/command_update
# /gripper/state_feedback

# 检查话题发布频率
ros2 topic hz /robot/target_pose
```

### Q2: 录制的帧数远少于预期

**症状：**
```
录制进度: 50 帧  (预期应该有1000+帧)
```

**可能原因：**
1. 时间对齐容差太小（默认50ms）
2. 某个话题没有发布
3. 消息时间戳不同步

**解决方法：**
- 检查所有话题是否正常发布
- 增大时间容差（修改代码中的 `tolerance=0.05`）

### Q3: 分析时提示文件不存在

**症状：**
```
错误：文件不存在 playback_eval/evaluation_0.hdf5
```

**解决方法：**
- 确认评估录制器已正确保存文件
- 使用绝对路径或相对路径
- 检查文件权限

### Q4: 跟踪误差很大（>10mm）

**可能原因及解决方法：**

1. **ServoP控制频率不足**
   - 检查播放频率是否为100Hz
   - 确认网络延迟

2. **机械臂响应慢**
   - 检查速度因子设置（SpeedFactor）
   - 确认机械臂负载是否过大

3. **数据集质量差**
   - 使用 `clean_dataset.py` 检查数据集
   - 查看是否有突变或丢帧

4. **播放速度过快**
   - 使用 `--rate 0.5` 降低播放速度
   - 观察误差是否减小

### Q5: 生成图表时报错

**症状：**
```
错误：需要安装 matplotlib 来生成图表
```

**解决方法：**
```bash
pip install matplotlib
```

## 高级用法

### 1. 批量分析多个评估文件

```bash
# 使用脚本批量分析
for file in playback_eval/evaluation_*.hdf5; do
    echo "分析 $file"
    python3 analyze_playback.py "$file" --plot
done
```

### 2. 自定义误差阈值

```bash
# 使用更严格的阈值
python3 analyze_playback.py playback_eval/evaluation_0.hdf5 \
    --pos-threshold 2.0 \
    --rot-threshold 1.0
```

### 3. 对比不同播放速率的效果

```bash
# 录制原速播放
python3 dataset_player.py data/episode_1.hdf5 --rate 1.0
# 保存为 evaluation_0.hdf5

# 录制慢速播放
python3 dataset_player.py data/episode_1.hdf5 --rate 0.5
# 保存为 evaluation_1.hdf5

# 对比分析
python3 analyze_playback.py playback_eval/evaluation_0.hdf5 --plot
python3 analyze_playback.py playback_eval/evaluation_1.hdf5 --plot
```

## 性能优化建议

### 基于评估结果优化系统

#### 1. 如果位置误差大（>5mm）

**可能改进方向：**
- **提高ServoP频率**：确保100Hz控制频率
- **优化通信延迟**：使用有线连接，避免无线
- **调整PID参数**：联系机械臂厂商调优
- **降低播放速度**：使用 `--rate 0.8` 等

#### 2. 如果旋转误差大（>2°）

**可能改进方向：**
- **检查姿态控制模式**：确认使用正确的姿态表示
- **校准机械臂**：可能需要重新校准
- **检查数据集**：确认录制时姿态稳定

#### 3. 如果夹爪误差大（>50）

**可能改进方向：**
- **增加Modbus读取频率**：目前10Hz，可提高到20Hz
- **检查夹爪响应**：可能需要调整力度/速度参数
- **优化插补算法**：改进状态反馈线程

#### 4. 如果误差波动大（标准差>2mm）

**可能改进方向：**
- **稳定控制环境**：减少外界干扰
- **检查传感器噪声**：可能需要滤波
- **优化轨迹平滑**：在录制时添加滤波

## 总结

播放评估系统提供了全面的播放质量分析工具，帮助你：

✅ **量化跟踪性能**：精确测量位置、旋转、夹爪误差
✅ **定位问题**：找到大误差发生的时间和位置
✅ **优化系统**：基于数据驱动的改进方向
✅ **验证效果**：对比优化前后的性能提升

**工作流程建议：**

1. 首次播放使用慢速（0.5x）并录制评估数据
2. 分析结果，识别主要问题
3. 针对性优化系统参数
4. 再次播放并录制，对比改进效果
5. 达到满意精度后，可进行正式应用

**关键指标目标：**
- 位置误差平均值：<3mm
- 位置误差95%分位：<5mm
- 旋转误差平均值：<1.5°
- 夹爪误差平均值：<30

达到这些指标后，数据集播放系统就可以用于VLA训练数据采集了！
