# Dataset Player 安全播放指南

## 新增安全特性（重要更新）

为了解决**机械臂当前位置与数据集起始位置差距过大导致突然移动**的安全问题，`dataset_player.py` 已添加完整的安全检查机制。

---

## 问题场景

### 危险情况示例
- 机械臂当前位置：`X=100, Y=-300, Z=400`
- 数据集第一帧：`X=-170, Y=-498, Z=270`
- **位置差距：280mm**

❌ **旧版本**：直接发送ServoP指令，机械臂会突然快速移动280mm，可能导致：
- 碰撞障碍物
- 机械损伤
- 安全事故

✅ **新版本**：自动检测差距，提供安全选项

---

## 新增功能

### 1. 自动安全检查 `check_start_position_safety()`

播放前自动对比当前位置与数据集起始位置：

```
======================================================================
安全检查：当前位置 vs 数据集起始位置
======================================================================

当前位姿:  X= 100.0 Y=-300.0 Z= 400.0 | RX= 180.0 RY=   0.0 RZ=  90.0
起始位姿:  X=-170.7 Y=-498.8 Z= 270.2 | RX= 179.1 RY=   2.7 RZ=  20.7

位置差距: 280.5 mm
旋转差距: 69.3 deg

⚠️  警告：差距超过阈值！
  位置阈值: 50.0 mm (当前: 280.5 mm)
  旋转阈值: 10.0 deg (当前: 69.3 deg)

直接播放可能导致机械臂突然大幅度移动！
======================================================================
```

**安全阈值：**
- 位置差距：50mm
- 旋转差距：10度

### 2. 自动移动到起始位置 `move_to_start_position()`

使用 **MovJ（关节空间运动）** 平滑移动到起始位置：
- 避开障碍物（关节空间规划）
- 可调速度（默认50%）
- 超时保护（30秒）

### 3. 交互式安全选项

当检测到位置差距过大时，提供三个选项：

```
⚠️  检测到位置差距过大！

选项1: 自动移动到起始位置（使用MovJ平滑运动）
选项2: 取消播放，手动调整位置
选项3: 忽略警告，强制播放（危险！）

请选择 [1/2/3]:
```

## 使用方法

### 1. 标准安全播放（推荐）

```bash
python3 dataset_player.py data/episode_1.hdf5
```

**流程：**
1. 加载数据集
2. 自动检查当前位置
3. 如果差距过大，提示选择：
   - 选1：自动平滑移动到起始点
   - 选2：取消播放，手动调整
   - 选3：强制播放（需二次确认）
4. 开始安全播放

### 2. 慢速播放（更安全）

```bash
python3 dataset_player.py data/episode_1.hdf5 --rate 0.5
```

适用场景：
- 首次播放测试
- 数据集包含高速运动
- 观察机械臂行为

### 3. 跳过安全检查（仅调试用）

```bash
python3 dataset_player.py data/episode_1.hdf5 --no-safety-check
```

⚠️ **警告**：仅当您**完全确定**当前位置与起始位置接近时使用！

### 4. 禁用自动移动

```bash
python3 dataset_player.py data/episode_1.hdf5 --no-auto-move
```

如果检测到差距过大，只会提示，不提供自动移动选项。

## 安全检查技术细节

### 位置差距计算

```python
# 笛卡尔空间欧氏距离
pos_current = [x_curr, y_curr, z_curr]
pos_target = [x_targ, y_targ, z_targ]
pos_diff = sqrt((x_curr-x_targ)² + (y_curr-y_targ)² + (z_curr-z_targ)²)
```

### 旋转差距计算

```python
# 姿态向量欧氏距离
rot_current = [rx_curr, ry_curr, rz_curr]
rot_target = [rx_targ, ry_targ, rz_targ]
rot_diff = sqrt((rx_curr-rx_targ)² + (ry_curr-ry_targ)² + (rz_curr-rz_targ)²)
```

### MovJ 移动策略

- **关节空间运动**：在关节角度空间插补，避免笛卡尔空间的直线路径
- **优点**：避开奇异点，更安全
- **速度控制**：默认50%速度，平滑启停
- **超时保护**：30秒超时，防止卡死

## 常见问题

### Q1: 为什么需要安全检查？

**A**: 如果机械臂当前位置与数据集第一帧差距很大（比如100mm），直接使用ServoP会导致机械臂**瞬间快速移动**到目标位置，这非常危险。

### Q2: 安全阈值可以调整吗？

**A**: 可以。在代码中修改 `check_start_position_safety()` 的参数：

```python
is_safe, ... = self.check_start_position_safety(
    position_threshold=100.0,  # 改为100mm
    rotation_threshold=20.0    # 改为20度
)
```

### Q3: MovJ 移动失败怎么办？

**A**: 可能原因：
1. 目标位置超出工作空间
2. 机械臂未使能
3. 服务未就绪

解决方法：选择"手动调整位置"，使用示教器移动

### Q4: 我确定位置接近，能跳过交互确认吗？

**A**: 如果差距在阈值内（<50mm位置，<10度旋转），会自动跳过交互，直接播放。

### Q5: 播放中可以暂停吗？

**A**: 按 `Ctrl+C` 可以立即停止播放。

## 技术改进总结

### 新增方法

1. **`get_current_pose()`**
   - 功能：获取机械臂当前位姿
   - 返回：`[x, y, z, rx, ry, rz]` numpy数组

2. **`check_start_position_safety()`**
   - 功能：对比当前位置与起始位置
   - 返回：安全性判断、位置差距、旋转差距

3. **`move_to_start_position()`**
   - 功能：使用MovJ平滑移动到起始位置
   - 参数：速度（默认50%）
   - 超时：30秒

### 修改方法

1. **`play()`**
   - 新增参数：
     - `auto_move_to_start=True`：启用自动移动功能
     - `safety_check=True`：启用安全检查
   - 播放前自动执行安全检查

2. **`main()`**
   - 新增命令行参数：
     - `--no-safety-check`：禁用安全检查
     - `--no-auto-move`：禁用自动移动
